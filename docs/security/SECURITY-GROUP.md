# ECS 网络与安全组配置

本项目通过 SSH 隧道管理，绑定的微信仅提供查询和查重。ECS 网络规则、SSH 身份与应用主密码是不同层次：更换服务器或 SSH 密钥不改变数据库密文，也不替代应用登录。

## 新服务器的入站规则

| 流量 | 要求 |
| --- | --- |
| SSH（默认 TCP 22） | 仅允许需要管理该服务器的可信来源，通常为当前电脑公网出口 IP 的 `/32` |
| 管理页 | 不对公网开放；仅绑定服务器 `127.0.0.1:18080`，由 SSH 转发访问 |
| PostgreSQL | 不开放公网或服务器 TCP 5432；生产配置只监听容器共享 Unix socket |
| 其他服务 | 独立核对其业务需要，本项目不要求额外开放 80、443、8000 或 18080 入站 |

在新 ECS 的实际安全组中配置 SSH 来源。换网络、出口 IP 改变或启用代理后，需要相应更新来源；仓库不保存某台服务器的固定公网地址。安全组识别网络来源，SSH 密钥授权连接持有者，应用主密码授权解密数据。

调整已有规则时，先验证新的受限规则能够建立另一条 SSH 连接，再移除旧的宽泛放行，保留云控制台访问能力。核对实例关联的全部安全组及共享规则，避免影响同机或同组的其他服务。部署脚本不会自行修改云安全组。

## 出站连接

微信适配器通过出站 HTTPS 长轮询接收消息，模型 API 也使用出站 HTTPS；不需要对公网开放回调端口。拉取容器、获取源码及模型文件需要各自软件源的网络访问。

| 流量 | 用途 |
| --- | --- |
| TCP 443 | 微信、模型接口、HTTPS 软件源和模型下载 |
| UDP/TCP 53 | 新服务器实际配置的 DNS 解析服务 |
| UDP 123 或实际校时服务 | 操作系统时间同步 |
| 其他维护流量 | 按新机器的软件源和已有业务单独核对 |

不要复制旧服务器的 DNS 或 NTP 地址作为新机器的永久依赖。按新机器实际配置的解析和校时目标设置规则；外部 API 使用域名且解析地址会变化，不把某次解析出的单个地址视为永久白名单。

安全组是否默认放行出站、不同规则的优先级和组间组合以实际云平台配置为准。仅添加几条允许规则不能证明其余流量已被拒绝；若采用严格白名单，先完整验证系统维护及其他业务需要，再收紧其余规则。

## 换机后的检查

1. 用新 ECS 私钥建立 SSH 连接，核对新服务器主机指纹。不要把私钥上传到应用目录或容器。
2. 在本机运行 `console.ps1 -Action Configure` 更新服务器地址、用户和私钥路径，再运行 `-Action Open`。
3. 管理页应只通过本机 `http://127.0.0.1:18080`（或配置的本机端口）访问；用原应用主密码或恢复密钥登录恢复后的密码库。
4. 检查记录、回收站和设置；微信或模型授权失效时重新配置。
5. 验证服务器公网不能直接访问管理端口和数据库端口。无需为正常微信查询开放额外入站规则。

主机指纹变化与用户 SSH 密钥更换也是不同事件：前者验证你连接的是哪台服务器，后者决定你能否登录。两者均不参与密码库的业务加密。
