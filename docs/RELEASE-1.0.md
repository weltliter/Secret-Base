# 1.0 版本说明

## 功能范围

- 单人密码库：主密码或恢复密钥登录；业务记录、设置和查询日志加密保存。
- Windows 双击入口自动建立 SSH 隧道并打开管理页；支持命令行连接、检查、状态查询和自选本地端口。
- 管理页支持新增、编辑、组合搜索与筛选、标签、重复检查、删除确认及 30 天回收站恢复。
- 绑定的微信只查询和查重；关键词与本地中文嵌入模型召回，DeepSeek Flash 排序，默认返回最多 3 条、可指定 5 条，弱匹配明确标注。
- 微信查询在管理端锁定后继续运行，首次登录启用查询自动恢复。管理会话固定 8 小时，锁定只撤销当前浏览器权限。
- 保留数据库备份/恢复、模型下载校验、隔离联调与资源检查工具。

## 安装与验证

从 `v1.0` 检出源码后，参照[运维说明](OPERATIONS.md)准备部署参数、机器密钥和模型。恢复演练使用隔离数据库和合成记录。

## 已知限制与后续需求

- 仅支持单人、绑定微信只读查询、SSH 隧道管理；尚未提供公网 HTTPS 管理入口。
- 8 小时管理会话没有闲置超时。关网页或断开 SSH 不保证会话立即失效，断网不自动清理已加载内容；用完先点击“锁定管理端”。
- 管理锁定不等于停止服务器解密；微信查询使用同一数据密钥。服务器运行时和机器密钥属于可信边界，本项目不是服务器不可解密的零知识系统。
- 查询结果会按现有设计以明文凭据回复到微信；服务器数据加密不保护已发送的聊天记录。
- 备份脚本只在执行时清理超过 7 天的备份，不自动安装计划任务。
- 闲置锁定、断网清屏、可选失联租约及 HTTPS 备选均见 [版本迭代需求](ITERATION-REQUIREMENTS.md)。状态为待排期，等待后续需求合并，建议时长未最终确定。
