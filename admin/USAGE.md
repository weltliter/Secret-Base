# 管理端使用指南

当前版本：**1.1，含上传恢复补丁**。ECS 连接与应用加密独立，数据库包含完整恢复元数据，提供网页备份、上传全量恢复及管理端自动锁定。验证结果见 [1.1 版本说明](../ecs/docs/history/RELEASE-1.1.md) 和 [补丁上线验证摘要](../ecs/docs/history/DEPLOY-1.1-RESTORE-20261117.md)，数据分工见 [程序与数据边界](../ecs/docs/DATA-BOUNDARY.md)，换机步骤见 [恢复指南](../ecs/docs/RECOVERY.md)。1.0 说明保留在 [历史版本说明](../ecs/docs/history/RELEASE-1.0.md)。

在自己的云服务器保存加密账号资料，通过绑定的微信账号用自然语言查询。默认返回最多 3 条候选（明确标识弱匹配），也可以要求“返回前 5 条”。查询结果仅含系统名称、网址、账号和密码；描述只参与检索。查重综合系统、网址和凭据判断，密码复用作为单独的可选提醒。微信只有查询权限；新增、修改、删除和恢复仅能通过电脑管理页完成。电脑删除经过确认后进入 30 天回收站。

这是单人服务。日常请求只接受绑定的微信身份，电脑管理页通过 SSH 隧道访问，不需要额外注册，管理端使用主密码登录。数据库和管理页不开放公网端口。

## 使用前的准备

程序可以部署到满足 Linux 和 Docker Compose 运行要求的新 ECS。将项目的 `ecs/` 作为服务端源码目录，私有状态目录默认为 `/var/lib/wechat-vault`，可通过服务器 `config.env` 的 `VAULT_STATE_DIR` 调整。本指南中的客户端命令均在 `admin/` 执行。首次使用需要：

- 新服务器对应的 SSH 私钥，仅保存在个人电脑；运行 `.\console.ps1 -Action Configure` 配置地址、用户名和私钥路径。
- 自己设置并保存的主密码，以及仅在首次初始化时显示的恢复密钥。
- DeepSeek API Key，在管理页中填写并加密保存。
- 使用自己的微信扫描官方登录二维码，完成唯一账号绑定。微信账号能否接入以实际扫码结果为准。

## 打开电脑管理页

**双击本目录 `admin/` 中的 `打开管理页.cmd` 即可。** 它会自动建立 SSH 隧道，等服务就绪后用默认浏览器打开 `http://127.0.0.1:18080`。使用期间保留启动窗口，用完后在该窗口按 `Ctrl+C` 关闭隧道。重复双击会复用已有的可用隧道；连接失败时保留错误信息，便于检查。

也可以在 Windows PowerShell 中进入 `admin/` 目录，运行：

```powershell
.\console.ps1 -Action Open
```

仅连接隧道、手动打开浏览器的原有方式仍可使用：

```powershell
.\console.ps1
```

保持窗口开启，在浏览器打开 `http://127.0.0.1:18080`。页面通过 SSH 加密隧道连接服务器；这个地址只在自己的电脑本地使用。按 `Ctrl+C` 可关闭隧道。

脚本会将 SSH 私钥复制到当前 Windows 用户专属的 `.local/ssh/<SID>/tunnel-key.pem`，只允许当前 Windows 用户读取，不修改原始密钥。主机指纹仅保存在本机私有目录；新主机首次连接前应核对指纹，之后主机密钥变化会拒绝连接。不要将 `.local` 或任何私钥提交到版本库。应用容器不读取或挂载这些 SSH 文件。

如果本地 18080 端口被占用，将唯一配置文件 `config.env` 中的 `VAULT_LOCAL_PORT` 改为 `18081`，然后重开隧道。

随后访问 `http://127.0.0.1:18081`。本机端口只允许 10000–65535，远端端口由 `VAULT_REMOTE_PORT` 指定，必须与 ECS 的 `VAULT_ADMIN_PORT` 一致。已有进程占用端口时会明确提示，不结束已有进程。

其他本机命令：

```powershell
.\console.ps1 -Action Check   # 检查端口、OpenSSH 和私钥文件
.\console.ps1 -Action Status  # 通过现有隧道查看服务状态
```

**实际连接配置只放在被 Git 忽略的 `config.env`**，仓库仅提供 `config.example.env` 模板。更换 ECS 或 SSH 密钥后重新运行配置命令，不需要修改应用代码或数据库。`Check` 显示端口已占用，而 `Status` 能正常读取时，表示隧道已经运行，直接打开页面即可。

## 初始化和录入

1. 设置主密码，将首次显示的恢复密钥保存在服务器以外的位置。
2. 在模型设置中填写 DeepSeek Key。
3. 生成微信官方登录二维码，使用自己的微信扫描并确认绑定。
4. 新增记录，填写系统名称、网址、检索描述，以及账号、密码、私密备注和自定义字段。标签可以留空、自行输入，或点击已有标签选择。

**只有标题、服务、用途描述和标签允许交给 DeepSeek。** 账号、密码、私密备注和自定义字段属于机密内容。用途描述可以写“去年给某客户部署测试环境时注册的云平台账号”，不要在这些检索描述中填写密码、API Key 或恢复码。

录入内容在写入数据库之前加密。输入的原始备注可以自由组织，自定义字段用于保存密保答案、API Key 等不固定的信息。修改记录时，不填写新的密码表示保留原密码。

## 管理端搜索与筛选

账号列表和回收站均支持组合筛选：关键词可搜索系统名称、网址、账号、检索描述和标签，也可限定搜索字段；空格分隔的多个词需全部匹配。标签按完整标签精确匹配，可多选“任一匹配”或“全部匹配”，也可仅查看有标签或无标签的记录。点击记录上的标签可以直接筛选该标签。

日期可按创建或更新时间筛选，包含起止当天，以当前设备时区为准；支持按更新时间、创建时间和系统名称排序。列表显示筛选结果数与总数，一键重置恢复默认列表。筛选在已登录管理页内存中执行，不调用 AI、不读取密码，也不写入浏览器本地存储；锁定和切换栏目会清空筛选条件。重复检查仍针对全部有效记录。

## 在微信中使用

可以这样查询：

```text
找一下去年给客户做演示用的云服务器账号
找一下去年给客户做演示用的云服务器账号，返回前 5 条
查一下有没有重复记录
```

每条结果只含系统名称、网址、账号、密码。查询和允许检索的记录描述使用同一个中文嵌入模型转成 512 维向量，结合关键词召回，再由 DeepSeek Flash 判断相关性。确切匹配排在前面；不足 3 条（或指定的 5 条）时，按向量相似度补充相近记录，并在微信中明确标为“弱匹配，可能不相关”。例如没有苹果相关记录时仍可返回相近候选，但不会声称找到了苹果账号。明确要求排除的记录不会被补回；总记录不足时按实际数量返回。密码始终从已存记录中原样取出。

重复判断综合系统名称、网址、账号、密码，以及补充资料差异：

| 类型 | 含义 | 处理方式 |
| --- | --- | --- |
| 凭据重复 | 系统名称、规范化网址、账号和密码都一致 | 仍需核对描述、标签、备注及自定义字段差异 |
| 疑似重复 | 账号密码一致，系统或网址匹配，另一个维度不同或缺失 | 可能是别名、不同入口或环境，人工核对 |
| 版本或冲突 | 同系统、同网址、同账号，密码不同 | 不当作可直接删除的重复记录 |
| 密码复用提醒 | 不同系统、网址或账号使用相同密码 | 默认不展示；管理页勾选“包含密码复用提醒”后查看，不作为删除依据 |

微信通道不提供新增、修改、删除、恢复或回收站管理。需要清理重复项时，在当前电脑通过 SSH 隧道打开管理页，核对记录后点击删除并确认。

删除后的记录立即退出普通搜索，在回收站保留 30 天，可在电脑管理页恢复。到期后清除当前数据库中的记录。网页备份默认保留 7 天，应用启动及每小时清理过期文件；命令行备份在执行时清理其独立目录。项目不会自动安装定时生成备份的任务。

按当前选择，查询结果会以明文账号密码回复到微信，微信聊天记录中会保留这些结果。运行日志不包含查询正文、结果正文、账号、密码或密钥。管理端“查询日志”加密保存查询文本、结果系统名称、匹配类别、向量相似度、模型状态和耗时；已知账号密码等秘密会在查询文本中先遮盖。日志保留 30 天、最多 2000 条，只能登录管理端查看。

## 语义检索与资源

云端使用 `BAAI/bge-small-zh-v1.5` 的量化 ONNX 模型，本地运行，不使用个人电脑算力或 GPU。公开模型权重约 24 MB，单线程推理；业务向量索引只放在应用内存中，重启后从加密描述重建，记录修改或删除后在下一次检索更新。模型文件不是业务数据，位于 `models/bge-small-zh-v1.5/` 并以只读方式挂载。数据库继续保存密文，不创建明文 pgvector 表。

模型资源、下载校验与复现实测方式见 [运维说明](../ecs/docs/OPERATIONS.md)。

## 锁定、重启和恢复

管理端登录与微信查询独立。通过 SSH 隧道打开管理页，输入主密码或恢复密钥登录；管理会话闲置 5 分钟或登录满 1 小时失效。点击、输入、滚动计为活动，自动轮询和下载不续期，过期不影响微信。

切后台、离开页面或主动锁定立即清理页面敏感状态，并尝试注销同一浏览器共享的管理会话；恢复需要重新认证。确认断网后同样清屏。关闭或断网通知可能无法送达，服务端期限负责兜底。独立浏览器会话互不撤销。已开始的备份下载可以在锁定后继续，最多 30 分钟；新下载需要重新登录。

主密码及恢复密钥使用的加密密钥信封存入数据库，随 `.dump` 一起备份。主密码本身不保存。首次登录后，查询启动信封写入私有状态目录的 `data/vault/query-unlock.json`，用独立的 `secrets/query-unlock.key` 加密；这两项不进入数据库备份。新服务器生成自己的机器密钥，恢复后再次登录启用自动查询，无需旧服务器的运行密钥。

恢复密钥与主密码同样需要妥善保存。忘记主密码时，可以在登录输入框粘贴完整的 `recovery:...` 恢复密钥。两者都丢失时，无法通过正常恢复流程恢复备份或登录管理端。SSH 私钥不用于加密密码库。

在管理端“备份与灾备”中生成并下载数据库，另存 SHA-256 校验文件。全量备份不受筛选影响，包含回收站、加密设置和查询日志。下载开始不等于本地已经验证；请按 [恢复指南](../ecs/docs/RECOVERY.md) 核验。备份、恢复、部署和测试命令统一见 [运维说明](../ecs/docs/OPERATIONS.md)。

1.1 补丁支持在同一页面上传 `.dump` 文件并全量恢复。勾选覆盖确认后，系统校验备份并在一个事务中删除全部现有应用数据、写入备份数据；失败回滚。成功后所有管理会话失效，使用备份对应的主密码或恢复密钥重新登录。操作步骤与验证结果见 [上传恢复补丁](../ecs/docs/PATCH-1.1-RESTORE.md)。

## 运行边界

- 微信通道通过出站 HTTPS 长轮询连接官方服务；数据库无公网端口，管理页面仅监听服务器回环地址（默认 `127.0.0.1:18080`）。
- 不做多用户、注册、角色管理或群聊共享。绑定身份以微信官方登录结果为准，不接受陌生人发消息自动绑定。
- 模型失败时使用本地检索结果或要求补充描述，不编造账号密码。
- 使用本地精确比对判断凭据是否相同；AI 无权直接读取机密字段、任意执行 SQL、访问 Shell 或调用任何业务写入接口。
- 数据库和备份泄露时，业务内容仍为密文；服务器运行内存及独立机器密钥属于可信边界，整台服务器被控制时不能保证数据保密。

详细的数据边界和验证要求见 [安全说明](../ecs/docs/security/SECURITY.md)。

阿里云安全组的具体设置见 [安全组配置](../ecs/docs/security/SECURITY-GROUP.md)。安全组由你在控制台调整，程序部署不会自动修改云安全组。
