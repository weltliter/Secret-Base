## 功能范围

- 单人密码库：主密码或恢复密钥登录；业务记录、设置和查询日志加密保存。
- Windows 双击入口自动建立 SSH 隧道并打开管理页；支持命令行连接、检查、状态查询和自选本地端口。
- 管理页支持新增、编辑、组合搜索与筛选、标签、重复检查、删除确认及 30 天回收站恢复。
- 绑定的微信只查询和查重；关键词与本地中文嵌入模型召回，DeepSeek Flash 排序，默认返回最多 3 条、可指定 5 条，弱匹配明确标注。
- 微信查询在管理端锁定后继续运行，首次登录启用查询自动恢复。管理会话固定 8 小时，锁定只撤销当前浏览器权限。
- 保留数据库备份/恢复、模型下载校验、隔离联调与资源检查工具。

## 交付包与使用

源码包：`releases/1.0/wechat-vault-1.0-source.zip`，解包后顶层目录为 `wechat-vault-1.0/`。同目录的 `wechat-vault-1.0-source.zip.sha256` 保存整个包的 SHA-256；包内 `MANIFEST.sha256` 列出除清单自身外全部交付文件的相对路径和 SHA-256。

包含源码、模板和静态资源、测试、客户端入口/默认配置/服务器主机公钥、运维脚本、文档、容器配置和依赖版本清单。客户端默认连接目标仍为本项目服务器，使用另一服务器时须修改配置并核对主机公钥。

不包含 `.local/`、`.venv/`、`.env`、SSH 私钥、机器密钥、运行数据、会话、模型、日志、数据备份或旧交付包。此包用于源码交付，不是离线运行包、数据备份或云端整目录覆盖包。首次部署还需安装依赖、下载并校验公开模型，以及单独准备密钥；详见 [运维说明](../OPERATIONS.md)。

在项目根目录核对整个包：

```powershell
$package = 'releases/1.0/wechat-vault-1.0-source.zip'
$expected = ((Get-Content -LiteralPath ($package + '.sha256') -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath $package -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw '交付包校验失败' }
```

Windows 客户端使用入口见 [README](../../../README.md)。源文件修改后需要重新生成包和清单，不能沿用旧校验值。恢复本版本源码时先解压到独立目录核验；程序回退与业务数据恢复分开处理，不覆盖现有数据、密钥、模型或备份。

## 已知限制与后续需求

- 仅支持单人、绑定微信只读查询、SSH 隧道管理；尚未提供公网 HTTPS 管理入口。
- 8 小时管理会话没有闲置超时。关网页或断开 SSH 不保证会话立即失效，断网不自动清理已加载内容；用完先点击“锁定管理端”。
- 管理锁定不等于停止服务器解密；微信查询使用同一数据密钥。服务器运行时和机器密钥属于可信边界，本项目不是服务器不可解密的零知识系统。
- 查询结果会按现有设计以明文凭据回复到微信；服务器数据加密不保护已发送的聊天记录。
- 备份脚本只在执行时清理超过 7 天的备份，不自动安装计划任务。
- 闲置锁定、断网清屏、可选失联租约及 HTTPS 备选均见 [版本迭代需求](ITERATION-REQUIREMENTS.md)。状态为待排期，等待后续需求合并，建议时长未最终确定。
