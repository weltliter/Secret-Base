## 功能与恢复边界

- ECS SSH 身份只用于建立连接，应用不读取或绑定 ECS 私钥、地址或用户名。新服务器可以使用自己的连接身份和查询机器密钥。
- 数据库结构版本 2 保存原始加密信封及完整业务数据；业务加密格式仍为 1。新备份是 PostgreSQL 17 custom-format 单数据库文件。
- 恢复需要兼容源码、数据库备份及原主密码或恢复密钥。SSH 私钥无法代替应用解密凭据。旧双文件备份经过显式验证迁移。
- 管理会话闲置 5 分钟、绝对期限 1 小时；页面隐藏、离开、确认断网时清理状态。锁定不停止微信查询。
- 网页备份落盘后流式下载，默认单生成任务、两条下载、7 天保留、5 GiB 配额、1 GiB 空闲预留；当前已鉴权下载在锁定后最多继续 30 分钟，不支持断点续传。

详细操作见 [恢复指南](../RECOVERY.md)、[运维说明](../OPERATIONS.md) 和 [数据边界](../DATA-BOUNDARY.md)。

- 16 项 Node 前端测试通过，覆盖用户活动、过期/离线/后台处理、晚到响应、注销与登录竞争、备份任务及原生下载链接。
- PowerShell 客户端检查通过：独立合成配置、更换 ECS 地址与私钥路径、端口冲突，不依赖个人实际配置。
- 在 Linux amd64 Docker、PostgreSQL 17.12 和 Python 3.12 中通过真实 HTTP 生成和下载 621,839,259 字节（约 593 MiB）备份，大小与 SHA-256 一致。
- 下载过程中注销成功，耗时 0.003 秒；新下载被拒绝，已开始传输正常完成，查询运行状态保持可用。应用 RSS 峰值 335,994,880 字节（约 320 MiB），验收容器内存上限 512 MiB、禁止 swap。
- 使用下载的单数据库文件恢复到全新数据库与新机器密钥；删除原机器运行密钥和启动信封，未提供旧 vault.json。主密码及恢复密钥均可解密，验证回收站、设置、日志、去重状态及序列。
- 在另一个专用 Docker 项目实际执行 `backup.sh` 与 `restore.sh`：新转储通过 UID 70 peer 认证的临时库预检、保存回退快照、恢复并重新登录；旧 tar 包通过隐藏输入原密码（未回显）验证、迁移和恢复，随后经真实 HTTP 解密合成记录。Docker socket 仅挂载到一次性运维测试助手，应用容器没有该挂载。
- 检查恢复后的实际加密字段、信封和运行日志，没有合成明文凭据、主密码或恢复密钥泄露；拒绝错误凭据及旧管理 Cookie。
- 独立 Edge 无头浏览器通过登录、备份页面、原生附件下载、锁定清屏、离线恢复和 390px 移动布局检查，未出现页面脚本错误或横向溢出。无头浏览器不产生真实标签遮挡，后台锁定使用受控 visibilitychange 事件；休眠、多页通知等由前端时钟/事件测试覆盖。

测试只使用合成数据，不连接正式数据库，不向微信或模型服务发送真实请求。外部授权失效时需要重新绑定或配置；不承诺离线环境可以重新下载依赖和模型。

## Git 与源码交付

本地回退标签为 `baseline-1.0-20261116`（提交 `a9a781a`）；它包括补齐后的原版模型下载工具。旧历史仅用于本地回退，不推送所有分支或标签。

公开源码使用独立干净历史的 `public-main` 分支及 `v1.1` 标签。源码包由 `ops/release/package.py` 从跟踪清单生成，不含私钥、数据库、备份、模型、虚拟环境或本机实际配置；包内 `MANIFEST.sha256` 校验各文件，包外 `.sha256` 校验整个源码包。

本次没有创建远程仓库、推送 GitHub 或部署正式 ECS。Git 只能回退代码；恢复旧数据格式仍须配套的数据库与密钥信封备份。
