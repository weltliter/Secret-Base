# 1.1 上传恢复补丁上线验证摘要（已脱敏）

本文件提供补丁上线的公开验证摘要，不包含正式环境的记录数量、服务器路径、连接身份或备份位置。完整运维记录由维护者保存在本地私有目录。

应用版本为 1.1，数据库结构版本为 2，加密格式为 1。补丁更新应用代码，无需数据库结构迁移。

部署前保存数据库一致性备份与运行文件，校验转储可读取及 SHA-256。上线检查确认应用和数据库健康、运行代码匹配发布清单、原有记录与密钥元数据保持一致。

管理页提供文件选择、覆盖确认和上传全量恢复入口；未登录的恢复请求返回 423。上线检查没有在正式数据库执行覆盖恢复。查询服务可重新连接。

补丁功能已在独立合成环境通过 181 项 Python 测试、18 项前端测试及 Edge 实际上传恢复验证。使用方法见 [恢复指南](../RECOVERY.md)，部署、备份与回退的通用操作见 [运维说明](../OPERATIONS.md)。

回退应用不会撤销用户后来执行的数据恢复或其他数据修改。真实数据库、运行密钥、私有配置、数据指纹和备份文件不属于公开源码。
